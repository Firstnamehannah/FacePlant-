    FacePlant: a plant phenotypic data model

    A LinkML data model for plant phenotypic data, based on the Minimum Information About a Plant Phenotyping Experiment (MIAPPE v1.2) checklist. Slot names follow the original MIAPPE codenames for traceability.

    URI: https://w3id.org/your-org/faceplant

    Name: faceplant
